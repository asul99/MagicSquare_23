---

## 1. YAML 문법

- **블록 자체는 유효한 YAML 구조로 보입니다.** 키(`red_phase` / `green_phase` / `refactor_phase`), `steps`·`rules`·`coverage`·`proceed_when` 리스트, 들여쓰기(2칸 기준)가 일관됩니다.
- **주의(붙여넣기 시):** `실패 원인이 "아직 구현되지 않음"과` 구간은 **유니코드 곱따옴표(`"` `"`)**입니다. 일반 ASCII `"`와 섞이면 가독성만 나빠지고, 플레인 스칼라에서는 보통 파싱 오류는 아닙니다. 다만 상위 문서가 YAML이 아니라면(예: 마크다운 안의 코드펜스) **펜스 밖으로 잘리거나 들여쓰기가 깨지면** 그때는 오류가 납니다. 그건 “내용 설계”가 아니라 **병합 위치** 이슈입니다.

(환경에 PyYAML 등이 없어 파서로 재검증하지는 못했고, 육안·구조 기준입니다.)

---

## 2. 누락된 필수 섹션

- **이 저장소·03 보고서 범위 안에는 `tdd_rules`만 정의되어 있고,** `forbidden`, `ai_behavior`, 프로젝트 컨텍스트 등 **다른 최상위 섹션 정의는 없습니다.**  
  따라서 “전체 `.cursorrules`에 반드시 있어야 하는 키”가 무엇인지는 **팀/과제 템플릿 없이는 여기서 단정할 수 없습니다.**
- 다만 **03 프롬프트가 “`tdd_rules` 블록만”**을 요구했으므로, 그 산출물만 놓고 보면 **의도된 범위 밖 누락**이지, 그 YAML 조각 **내부**의 필수 키 누락은 아닙니다.

---

## 3. `tdd_rules`와 `forbidden` 간 충돌

- 워크스페이스에 **`forbidden` 문구가 없어** 문장 단위 충돌은 **검증 불가**입니다.
- 나중에 `forbidden`에 넣기 쉬운 문구와 **논리적으로 부딪칠 수 있는 지점**만 짚으면:
  - **green_phase:** “이름 변경, 추출, 구조 정리, **스타일 정리 금지**”
  - **refactor_phase:** “**명명 개선** … 구조 개선만”
  - `forbidden`에 **“린트/포맷 통과 유지”, “경고는 항상 즉시 제거”** 같은 규칙이 있으면, **green에서 문법/린트만 고치는 행위**가 리팩터/스타일에 가깝다고 해석될 여지가 있습니다(해석에 따라 충돌).
  - `forbidden`에 **“실패하는 테스트/빌드 상태 금지”**가 있으면, 순수 **red_phase**(의도된 실패)와 **표면적으로** 상충할 수 있습니다(실제로는 단계 구분으로 풀 수 있지만, 문장만 보면 모순처럼 읽힐 수 있음).

---

## 4. Cursor AI가 실제로 일관되게 따르기 어려운 규칙

`.cursorrules`는 **에이전트에게 읽히는 지침**이지, Cursor가 **`next_phase`를 실행하는 상태 머신**으로 해석하지는 않습니다.

- **`proceed_when` / `next_phase`:** “지금 red인지 green인지”를 **세션/도구가 강제하지 않습니다.** 한 번의 편집에 테스트 추가·구현·소규모 정리가 섞이기 쉬워, 문서상 사이클과 **실제 행동이 어긋날 수 있습니다.**
- **red의 “프로덕션 코드 작성·수정하지 않는다”:** 최소 스텁(컴파일용 빈 구현 등)을 **테스트 실행을 위해** 넣는 경우와 경계가 모호합니다.
- **refactor의 커버리지:** “리팩터 전 대비 낮아지지 않는다(측정 가능한 경우)”는 **도구로 수치를 읽고 비교**하지 않으면 모델이 스스로 증명하기 어렵습니다.
- **green의 “통과가 테스트 완화가 아닌 실제 구현에 의한 것”:** 모델이 **스스로 객관적으로 판정**하기 어렵고, 주관적 해석에 가깝습니다.

---

**요약:** YAML 조각은 구조상 문제 없어 보이고, 03 범위상 다른 섹션 미포함은 설계상 그렇게 정한 것입니다. `forbidden`은 원문이 없어 충돌은 확인 못 했고, 위와 같은 **잠재 충돌 유형**만 가능합니다. `ai_behavior`/`phase`류는 **에이전트가 기계적으로 보장하기 어려운 규칙**이 섞여 있습니다.

`forbidden`·`ai_behavior` 초안 텍스트를 주시면, 그때는 3·4번을 문장 단위로 다시 짚어 드리겠습니다.
